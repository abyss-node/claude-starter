# Your plan

Your Claude plan decides how fast you use up your limit, and so which rules
tier fits you. Find yours:

{{plans}}

- **Pro:** stay on the starter tier. The `verifier` agent runs on a larger
  model, so use it on work that matters rather than on every edit.
- **Max, Ultra, Team or Enterprise:** the full tier exists, but start on
  starter unless you already run several agents at once.
- **API key:** you pay for every token, so start on starter and keep an eye
  on `/usage`.

On a subscription, `/usage-credits` sets up paid credits for when you hit the
limit. `/starter:setup` asked which tier you wanted. To change it, run
`/starter:setup` again. `/model` shows and changes the model.
